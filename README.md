# Signeon

Naye Signeon e-commerce website ka frontend project folder. Iski asal
design/coding baad mein karenge.

Planned structure (jab design/build start hoga, roughly ye jesa rahega —
Vintage Artisans ki tarah):

```
signeon/
├── index.html
├── shop.html
├── product.html
├── cart.html
├── checkout.html
├── about.html
├── contact.html
├── css/
├── JS/
└── images/
```

Backend aur Admin panel Vintage Artisans wale hi shared rahenge (ek hi
backend, ek hi admin panel — store-wise data alag dikhega, jesa pehle
discuss hua tha). Ye folder sirf Signeon ki apni website (frontend) files
k liye hy.
